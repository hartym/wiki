## Computer science

### The Pragmatic Programmer

* [The Pragmatic Programmer, 20th Anniversary Edition - pragprog.com](https://pragprog.com/titles/tpp20/the-pragmatic-programmer-20th-anniversary-edition/)

The 1999 original is subtitled "From Journeyman to Master"; the 2019 rewrite is the one to buy.

### Design Patterns

Must read.

* [Design Patterns: Elements of Reusable Object-Oriented Software - Amazon](https://www.amazon.fr/Design-Patterns-Elements-Reusable-Object-Oriented/dp/0201633612)

If you need to remember only one thing, it should be the two rules of Object Oriented Programming:

* Favor **object composition** over **class inheritance**.
* Program to an **interface**, not an **implementation**.

### Patterns of Enterprise Application Architecture

* [Patterns of Enterprise Application Architecture - Martin Fowler](https://martinfowler.com/books/eaa.html)
* [EAA Catalog - Martin Fowler](https://martinfowler.com/eaaCatalog/)

### The Art of Computer Programming

Only try to read it if you have a lifetime you can dedicate to it.

* [The Art of Computer Programming - Donald Knuth's own page](https://www-cs-faculty.stanford.edu/~knuth/taocp.html)
