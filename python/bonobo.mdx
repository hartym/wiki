Bonobo is an [extract-transform-load toolkit for python 3.5+](https://bonobo-project.org/), aiming for simplicity.

> **Note**: not actively maintained at the moment. The last release is 0.6.4, from May 2019.

Bonobo is a rewrite / cleanup of rdc.etl for Python 3.5+. It's a work in progress, but already useable. Maybe.

## Quick start

See the [Bonobo tutorial](https://docs.bonobo-project.org/en/latest/tutorial/index.html).

## rdc.etl (for python 2.7+)

rdc.etl, Bonobo's ancestor, is no longer developed: its last release is 1.0.0a6, from March 2014. You can still [read the docs of rdc.etl](https://rdcetl.readthedocs.io/).
