Notes on the JavaScript and TypeScript ecosystem, mostly from the TypeScript side. The four pages
below follow the [State of JS](https://stateofjs.com/) categories, which is the closest thing the
ecosystem has to agreed vocabulary.

## Backend frameworks and runtimes

* <Link to="web-frameworks" /> - HTTP frameworks (Hono, Fastify, Express, NestJS, Elysia), the Node,
  Deno and Bun runtimes, and the WinterTC portability work.

## Meta-frameworks

* <Link to="meta-frameworks" /> - Next.js, Astro, Nuxt, SvelteKit, React Router and TanStack Start,
  plus where React Server Components actually ship.

## Front-end frameworks

* <Link to="frontend-frameworks" /> - React, Vue, Angular, Svelte and Solid, compared on their
  reactivity models rather than their syntax.

## Build tooling

* <Link to="build-tools" /> - Vite and Rolldown, esbuild, Rollup, webpack, Turbopack, Rspack, the
  TypeScript compiler port, linters, test runners and package managers.
